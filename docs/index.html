UN HÔTE. JUSQU’À TROIS AMIS.

Casque ou téléphone,
la même équipe.

Les positions, le corps, les mains et l’arme de chaque Nebula sont partagés. Les joueurs mobiles peuvent voir les gestes des joueurs VR; l’hôte conserve l’état des ennemis et les dégâts.

  1. 1

    Ouvrez un salon

    L’hôte choisit le niveau, puis ouvre le salon dans le menu du jeu.

  2. 2

    Partagez l’adresse

    Sur le même Wi-Fi, utilisez l’IP locale affichée. Par Internet, utilisez l’IP publique et le port UDP 24721; l’option UPnP tente de l’ouvrir sur le routeur.

  3. 3

    Partez à quatre

    Les amis rejoignent l’adresse. Une fois l’équipe réunie, l’hôte lance l’expédition. Installez tous la même version.

La connexion Internet directe dépend du routeur. Si UPnP échoue, une redirection du port UDP 24721 est nécessaire. Les réseaux derrière un CGNAT peuvent bloquer la connexion : cette version n’intègre pas de relais. La coop a été testée sur quatre instances locales; la validation entre appareils et réseaux distincts reste à faire.

BIEN DÉMARRER

Installer le prototype.

Sur Meta Quest

Téléchargez l’APK Quest sur un ordinateur. Avec le mode développeur activé sur votre casque, installez-le par SideQuest ou avec adb install -r Nebula-VR-Quest-0.21.1.apk. Lancez ensuite « Nebula VR » dans les sources inconnues. La mise à jour conserve l’identifiant de l’ancien prototype Quest.

Sur Android

Ouvrez l’APK Android sur votre téléphone et autorisez son installation depuis votre navigateur si Android le demande. Lancez « Nebula VR Mobile » en paysage. Le joystick gauche déplace Nebula; glissez au centre droit pour regarder. Les boutons servent à tirer, sauter, frapper, changer d’arme, recharger, aspirer et utiliser le grappin.

Vérifier une mise à jour

Au démarrage, les deux APK consultent le manifeste de version de ce dépôt. Si une version plus récente existe, le menu propose son téléchargement. Android demande ensuite de confirmer l’installation. Les fichiers proviennent des Releases du dépôt NebulaVR.
